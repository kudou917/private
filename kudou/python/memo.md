## インタプリタとコンパイル型言語の違い

Pythonはインタプリタ型言語と呼ばれ、CやC++などの静的コンパイル型言語と対比されます。その違いを簡単に整理しましょう。

- コンパイル型言語: プログラムを機械語に変換するコンパイルを事前に行い、実行時にはその機械語のバイナリをロードしてCPUで直接実行します。例としてC/C++、Rust、Goなどがあります。コンパイルに時間がかかりますが、一度コンパイルされたプログラムの実行速度は高速です。

- インタプリタ型言語: プログラムの実行時に逐次コンパイルや解釈を行います。PythonやRuby、JavaScript（ブラウザ上の実装）などが該当します。実行のたびにコードを解析・解釈するため一概に実行速度は遅めですが、ソースコードの変更反映が容易で対話的な実行が可能です。

## for文

for <識別子> in <リストやタプルなどのオブジェクト:iterable> :
    <プログラム文>
    ...
の形をしています。

<リスト、タプル、などのオブジェクト>の要素毎に、その値が<識別子>に割り当てられて、:の後に続く　<プログラム文>　が実行されます。

ex:range(0,10,1)は0から始まって、10以下の、1づつ増える整数の列を表現しています。

for文による繰り返しとリスト・タプル
きまった操作の繰り返しはコンピュータが最も得意とする処理のひとつです。 リストのそれぞれの要素にわたって操作を繰り返したい場合はfor文を用います。

リスト ls の要素全てに対して、実行文 を繰り返すには次のように書きます。

for value in ls:
    実行文
for で始まる行の in の後に処理対象となるリスト ls が、in の前に変数 value が書かれます。

ls の最初の要素、すなわち ls[0] が value に代入され 実行文 が処理されます。 実行文 の処理が終われば、ls の次の要素が value に代入され、処理が繰り返されます。 このようにして、ls の要素に対する処理が len(ls) 回繰り返されると、for文の処理が終了します。

ここでの in の働きは、先に説明したリスト要素の有無を検査する in とは異なることに、 そして、if文と同様、 実行文 の前にはスペースが必要であることに注意してください。

次に具体例を示します。 3つの要素を持つリスト ls から1つずつ要素を取り出し、変数 value に代入しています。 実行文 では value を用いて取り出した要素を参照しています。
