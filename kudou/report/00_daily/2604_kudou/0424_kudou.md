# 組み込み講座メモ

- 配列:同じデータ型の複数の値を、連続したメモリ領域にまとめて格納するための仕組み  
アパートやロッカーに例えられる。scores という名前のアパートがあり、その「0号室」「1号室」「2号室」... に、それぞれ点数データが入っているイメージです。  
40人分の点数（int型）を、scores という1つの名前でまとめて管理できます。  
i++:インクリメント。変数を1増加させる事が出来る。
前置か後置かで意味合いが異なるらしいが、一旦気にしないようにしよう。  
宣言は「データ型 配列名[要素数];」
ex.int score [10]

- forの条件式は、（1初期化2条件式3変化）を1行にまとめてかける。
ex.for(i=0;i<5;i++){
    printf("~")
}

- i++:インクリメント。変数を1増加させる事が出来る。

コードフラッシュメモリ：マイコンのプログラムを格納するための不揮発性フラッシュメモリ。

データフラッシュメモリ：電源を切ってもデータを保持できる不揮発性半導体メモリで、書き込みや消去が可能な記憶装置。

フラッシュパッチ（リマップ）機能は、ARMプロセッサのファームウェアを書き込んだROMが割り当てられ、リスタート・アドレスからスタートします。ファームウェアは、OSに制御を渡す前にメモリ・マップを再構築し、OSの動作に必要なメモリ・リソースを確保します。この機能は、特にARMプロセッサの動作において重要な役割を果たします。
