# 組み込み講座メモ

リポジトリ  ファイルやディレクトリの状態を記録する場所。保存された状態は、内容の変更履歴として格納されている。  
  
リモートリポジトリ  サーバーに設置。複数人で共有するためのリポジトリ  
ローカルリポジトリ  ユーザー一人が利用するために自分の手元のマシンに配置するリポジトリ。  

コミット  リポジトリにファイルなどの追加・変更をする操作  

ワークツリー  自分たちが実際に作業しているディレクトリ

プッシュ  リモートリポジトリにローカルリポジトリ内の変更をアップロードすること。  

クローン  リモートリポジトリの複製  
プル  リモートリポジトリからローカルリポジトリを更新するにはプルというそうさが必要である。  

マージ  gitの変更箇所を統合する。  
ブランチ  履歴の流れを分岐して記録していくもの。分岐したブランチをマーキングすることも可  
  
フェッチ  リモートリポジトリの履歴を確認したい「だけ」の時に使う。  
  
オームの法則 V=IR  
    V　電圧  
    I　電流  
    R　抵抗  

フローティング状態とは、回路や端子がGNDやVCCなどの基準電位に接続されておらず、電位が不定の状態。  
Arduino UNO R4 WiFiは、Arduino IDEでプログラムを書き込み、Wi-Fi接続やLEDマトリックス操作が可能な最新開発ボードです。  
発光ダイオード（はっこうダイオード、英語: light-emitting diode: LED、エルイーディー）とは、ダイオードの1種で、順方向に電圧を加えた際に発光する半導体素子である。発光原理にはエレクトロルミネセンス (EL) 効果を利用している。また、有機エレクトロルミネッセンス（OLEDs[注 1]、有機EL）も分類上は、LEDに含まれる。　　
デジタルマルチメーター（DMM）は、電圧・電流・抵抗などを測定できる汎用計測器で、測定値をデジタル表示することで読み取りやすさと高精度を実現しています。  
プルアップ抵抗は、電子回路の入力端子が「浮いている」状態にならないように、高電位に固定するための抵抗  

[テスターの計測方法] [https://denkirabo.com/tesuta/tsukaikata/]
  
受動素子（Passive element）は、回路において電力を消費したり蓄えたりするが、増幅や整流などの能動的な動作は行わない素子を指します。外部からの電気に対して受動的に影響を受けるため、「受動素子」と呼ばれます。能動素子（トランジスタやICなど）が電力を増幅したり信号を変化させるのに対し、受動素子は電気の流れを整えたり、信号の特性を制御する役割を持ちます。

能動素子は、入力信号として小さな電力、電圧、または電流を受け取り、外部から供給される電力を利用して大きな出力信号に変換できる素子です。入力と出力の比率は利得と呼ばれます。能動素子は、供給される電気的エネルギーに対して自ら働きかけるため、回路内で能動的に影響を与えることができます。

スイッチング電源  
スイッチング電源（スイッチングでんげん、英語：switched-mode power supply、略称：SMPS）あるいはスイッチング方式直流安定化電源とは、スイッチングトランジスタなどを用い、フィードバック回路によって半導体スイッチ素子のオン・オフ時間比率（デューティ比）をコントロールする事により出力を安定化させる電源装置である。スイッチング式直流安定化電源とも呼ぶ。商用電源の交流を直流電源に変換する電力変換装置などとして広く利用されており、小型、軽量で、電力変換効率も高い。一方で、高速にスイッチングを行う事から電波障害（EMI）が発生しやすい。[https://ja.wikipedia.org/wiki/%E3%82%B9%E3%82%A4%E3%83%83%E3%83%81%E3%83%B3%E3%82%B0%E9%9B%BB%E6%BA%90]
