# 組み込み講座メモ

- char = %s
- #define word 数字 プログラミング上で出てきたwordを指定の数字として定義する。定義部分の数字だけ都度変更したいプログラミングを作成する際に使う。

- strcmp(char*s1,char* s2),  右辺と左辺を比べて同じ文字であった場合、戻り値を0として出力する。ifの条件などで使われる。
- strcpy(char*s1,char* s2)  右辺の文字列を左辺の文字列変数にコピーする。文字列配列に一気にコピーを行いたいときに使う。
- strcat(char*s1,char* s2)  右辺の文字列を左辺の文字列変数に追加する。まとめたいときに使う。
- atoi(char*s1) char*s1の文字列をintに変換する。
